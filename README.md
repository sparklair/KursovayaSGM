## 1. Установка виртуального окружения (необходимо для работы некоторых скриптов с дополнительными библиотеками)

```PowerShell
# Перейдите в папку проекта
cd путь\к\папке\проекта

# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
venv\Scripts\activate

# При успешной активации в начале строки появится (venv)
```
Если при активации виртуального окружения выдаёт ошибку, дайте право PS запускать процессу скрипты этой командой:
```PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```
Теперь ошибок быть не должно. Активируйте venv
```PowerShell
venv/Scripts/activate
```
## 2. Установка зависимостей
```PowerShell
# Убедитесь, что виртуальное окружение активировано, затем:
pip install -r requirements.txt
```
